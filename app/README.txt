CLAUDE x WHATSAPP
=================
1) Double-click __START.bat (root folder).
2) Answer the questions (language, bot name, group, number, Claude accounts).
3) Link WhatsApp with the 8-character code shown (Linked devices > Link with phone number).
4) A little robot appears next to the clock. Right-click it: show/hide the Claude terminal, logs, restart, quit.

Needs: Node.js (https://nodejs.org) and a Claude account. Claude Code is installed by the wizard if missing.
No browser extension is needed.

app/  = program files      data/ = your settings, WhatsApp login and logs (never share this folder)
